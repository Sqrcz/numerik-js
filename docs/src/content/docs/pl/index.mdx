## Przegląd

`@slashlab/numerik-js` to biblioteka TypeScript bez zależności produkcyjnych. Walidacja informuje o tym *dlaczego* dane są nieprawidłowe, a nie tylko *że* są nieprawidłowe. Typy są dołączone do biblioteki — nie potrzebujesz paczki `@types/`.

## W skrócie

```ts
import { Numerik, Gender } from '@slashlab/numerik-js'

// Sprawdzenie poprawności
Numerik.pesel().isValid('92060512186')   // true
Numerik.nip().isValid('5260250274')      // true

// Szczegółowe wyniki z informacją o błędzie
const result = Numerik.pesel().validate('92060512185') // błędna cyfra kontrolna
result.isFailed()                        // true
result.getFirstFailure()?.reason         // ValidationFailureReason.InvalidChecksum

// Parsowanie do obiektu z danymi
const pesel = Numerik.pesel().parse('92060512186')
pesel.getBirthDate()                     // Date — 1992-06-05
pesel.getGender()                        // Gender.Female
pesel.getAge()                           // obliczane na bieżąco
pesel.isAdult()                          // true
```

## Kluczowe właściwości

- **Brak zależności produkcyjnych** — podstawowa biblioteka nie ma żadnych zewnętrznych zależności.
- **Dołączone typy** — typy TypeScript są dołączone do biblioteki; nie potrzebujesz paczki `@types/`.
- **ESM + CJS** — dostarcza oba formaty; działa w Node, Deno, Bun i bundlerach.
- **Precyzyjne komunikaty błędów** — enum `ValidationFailureReason` obejmuje błędy formatu, sumy kontrolnej, zakodowanej daty i semantyczne.
- **Integracja z Zod** — opcjonalne schematy Zod dostępne poprzez dodatkową ścieżkę importu `/zod` (wymaga zewnętrznej zależności `zod`).
- **Ochrona przed zbyt długimi danymi wejściowymi** — dane wejściowe przekraczające 32 znaki są natychmiast odrzucane.
